overview: I was tasked with creating an instructional document that teaches how to use a piece of software to a target audience. I chose Pepakura, a papercraft unfolding software. I targeted my document at readers with prior experience in 3D modeling.

approach: I created a simple textured bread loaf model to serve as the sample project. This gave my audience a tangible product and end goal. My instructions also accounted for users who want to use their own custom 3D models, because most users likely have a specific project in mind before starting the tutorial.

revisions: Some images in my initial project were too small, so I made them larger while keeping their sizes consistent across the document. My document was also unclear in certain areas. To improve it, I added a diagram of the entire Pepakura screen and labeled each section. Before I added this diagram, it was unclear where users could find the 2D layout if they did not have Pepakura open or had taken a wrong step. I also received feedback that I had not explained how to navigate the file picker when importing files. To address this, I defined my target audience more explicitly. This allows me to avoid overexplaining basic tasks.

learning: When I first got started on this project, I did not realize the difference between an instructional document and software documentation. I was under the false impression that I would be creating software documentation that covered every feature of Pepakura in no particular order. Up until this point, I had used instructional documents and software documentation in my personal life, but I had never slowed down enough to distinguish between the two. I have also always had a tendency to skim through instructional documents, causing me to miss information at times. This assignment has taught me that instructional documents serve as the entry point to learning any piece of software, while more detailed documentation is intended for later reference. While trying to make my document as clear and explicit as possible, I developed an appreciation for instructional documents, and I have recently been reading them more carefully in my personal life.
